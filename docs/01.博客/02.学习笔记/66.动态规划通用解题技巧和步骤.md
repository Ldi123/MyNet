# 🚀 动态规划通用解题技巧和步骤

## 📋 标准解题五步法

### 🎈 Step 1: 确定DP含义（最关键！）

**核心思想：明确dp[i]或dp\[i][j]代表什么**

#### 常见定义模式：

```java
// 模式1：以i结尾的最优解
dp[i] = 以第i个元素结尾的最大/最小/数量

// 模式2：前i个元素的最优解  
dp[i] = 前i个元素的最大/最小/数量

// 模式3：从起点到(i,j)的最优解
dp[i][j] = 从(0,0)到(i,j)的最优解

// 模式4：区间DP
dp[i][j] = 区间[i,j]内的最优解

// 模式5：状态DP
dp[i][state] = 第i个位置在state状态下的最优解
```

### 🔄 Step 2: 推导状态转移方程

**核心：当前状态如何从之前状态推导而来**

#### 常见转移模式：

```java
// 选择型：选或不选
dp[i] = max(dp[i-1], dp[i-1] + nums[i])

// 路径型：从哪里来
dp[i][j] = dp[i-1][j] + dp[i][j-1]

// 决策型：多种选择取最优
dp[i] = min(dp[i-1], dp[i-2], dp[i-3]) + cost[i]

// 区间型：分割点枚举
dp[i][j] = min(dp[i][k] + dp[k+1][j]) for k in [i,j-1]
```

### 🌱 Step 3: 确定初始状态

**边界条件的正确设置**

```java
// 常见初始化模式
dp[0] = 0;              // 空集/起点
dp[0] = nums[0];        // 第一个元素
Arrays.fill(dp, INF);  // 最小值问题
Arrays.fill(dp, -1);   // 不可达状态
dp[0][0] = 1;          // 路径问题起点
```

### 🔄 Step 4: 确定遍历顺序

**保证计算当前状态时，依赖的状态已经计算完毕**

```java
// 一维：通常从前往后
for (int i = 1; i < n; i++)

// 二维：根据依赖关系
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++)  // 或倒序
}

// 区间DP：按区间长度递增
for (int len = 2; len <= n; len++) {
    for (int i = 0; i <= n - len; i++) {
        int j = i + len - 1;
    }
}
```

### 🎯 Step 5: 返回结果

**根据DP含义确定答案位置**

```java
return dp[n-1];        // 最后一个位置
return dp[n];          // 处理n个元素后
return dp[0][n-1];     // 区间[0,n-1]
return Arrays.stream(dp).max().getAsInt(); // 所有状态最优
```

## 🏷️ 经典DP类型和模板

### 📍 1. 线性DP

#### 🔹 最大子数组和

```java
public int maxSubArray(int[] nums) {
    // dp[i] = 以nums[i]结尾的最大子数组和
    int dp = nums[0], result = nums[0];
    for (int i = 1; i < nums.length; i++) {
        dp = Math.max(nums[i], dp + nums[i]);
        result = Math.max(result, dp);
    }
    return result;
}
```

#### 🔹 最长递增子序列

```java
public int lengthOfLIS(int[] nums) {
    // dp[i] = 以nums[i]结尾的最长递增子序列长度
    int[] dp = new int[nums.length];
    Arrays.fill(dp, 1);
    int result = 1;
    
    for (int i = 1; i < nums.length; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        result = Math.max(result, dp[i]);
    }
    return result;
}
```

### 📍 2. 背包DP

#### 🔹 0-1背包模板

```java
public int knapsack01(int[] weights, int[] values, int W) {
    // dp[i][w] = 前i个物品，容量w的最大价值
    int[][] dp = new int[weights.length + 1][W + 1];
    
    for (int i = 1; i <= weights.length; i++) {
        for (int w = 1; w <= W; w++) {
            // 不选第i个物品
            dp[i][w] = dp[i-1][w];
            // 选第i个物品（如果放得下）
            if (w >= weights[i-1]) {
                dp[i][w] = Math.max(dp[i][w], 
                    dp[i-1][w-weights[i-1]] + values[i-1]);
            }
        }
    }
    return dp[weights.length][W];
}
```

#### 🔹 完全背包模板

```java
public int completeKnapsack(int[] weights, int[] values, int W) {
    // dp[w] = 容量w的最大价值
    int[] dp = new int[W + 1];
    
    for (int i = 0; i < weights.length; i++) {
        for (int w = weights[i]; w <= W; w++) {
            dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[W];
}
```

### 📍 3. 区间DP

#### 🔹 区间DP模板

```java
public int intervalDP(int[] nums) {
    int n = nums.length;
    // dp[i][j] = 区间[i,j]的最优解
    int[][] dp = new int[n][n];
    
    // 按区间长度递增
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            dp[i][j] = Integer.MAX_VALUE;
            
            // 枚举分割点k
            for (int k = i; k < j; k++) {
                dp[i][j] = Math.min(dp[i][j], 
                    dp[i][k] + dp[k+1][j] + cost(i, k, j));
            }
        }
    }
    return dp[0][n-1];
}
```

### 📍 4. 状态机DP

#### 🔹 买卖股票模板

```java
public int maxProfit(int[] prices) {
    // 状态：0-持有股票，1-不持有股票
    int hold = -prices[0];  // 持有股票的最大利润
    int sold = 0;           // 不持有股票的最大利润
    
    for (int i = 1; i < prices.length; i++) {
        int newSold = Math.max(sold, hold + prices[i]);  // 卖出
        int newHold = Math.max(hold, sold - prices[i]);  // 买入
        sold = newSold;
        hold = newHold;
    }
    return sold;
}
```

### 📍 5. 路径DP

#### 🔹 网格路径模板

```java
public int uniquePaths(int m, int n) {
    // dp[i][j] = 到达(i,j)的路径数
    int[][] dp = new int[m][n];
    
    // 初始化边界
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    
    // 状态转移
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
        }
    }
    return dp[m-1][n-1];
}
```



## ✨ DP数组可以压缩的条件

### 核心原理：**状态转移只依赖于有限的前面状态**

### 1. 时间维度压缩

当 `dp[i][j]` 只依赖于：

- `dp[i-1][...]` (上一行)
- `dp[i][j-1], dp[i][j-2], ...` (当前行前面的元素)

### 📋 压缩技巧分类

### 🔥 技巧1：二维→一维（最常见）

#### 适用条件：

```
dp[i][j] = f(dp[i-1][j], dp[i][j-1], ...)
```

#### 压缩方法：

```java
// 原始二维
int[][] dp = new int[m][n];

// 压缩为一维
int[] dp = new int[n];
```

### 🔥 技巧2：滚动数组

#### 适用条件：

当前状态只依赖前k个状态时

```java
// 原始
int[][] dp = new int[n][...];

// 滚动数组（k=2的情况）
int[][] dp = new int[2][...];
// 使用 i % 2 和 (i-1) % 2 来滚动
```

### 🔥 技巧3：倒序遍历

#### 适用条件：

避免同一行数据被重复使用

```java
// 0-1背包的经典技巧
for (int i = 0; i < n; i++) {
    for (int j = W; j >= weight[i]; j--) {  // 倒序！
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

### 🚨 压缩时的注意事项

#### ⚠️ 1. 遍历顺序很重要

```java
// 错误：会重复使用当前行的值
for (int j = 0; j < n; j++) {
    dp[j] = dp[j] + dp[j-1];
}

// 正确：0-1背包必须倒序
for (int j = W; j >= weight; j--) {
    dp[j] = Math.max(dp[j], dp[j-weight] + value);
}
```

#### ⚠️ 2. 保存必要的中间值

```java
// 当需要左上角dp[i-1][j-1]时
int prev = dp[0];  // 保存左上角
for (int j = 1; j <= n; j++) {
    int temp = dp[j];
    // ... 状态转移
    prev = temp;  // 更新左上角
}
```

#### ⚠️ 3. 边界条件处理

```java
// 确保边界正确初始化
dp[0] = 初始值;
for (int i = 1; i <= n; i++) {
    dp[i] = 边界值;
}
```

### 🎉 小结：压缩判断技巧

#### ✅ 可以压缩：

1. **状态转移只看前面有限行/列**
2. **没有"跳跃式"依赖**（如dp\[i][j]依赖dp\[i-3][j-2]）
3. **转移方程中的索引有规律**

#### ❌ 难以压缩：

1. **需要查看任意历史状态**
2. **状态转移有复杂的跳跃模式**
3. **需要同时保存多个维度的历史信息**

#### 🔧 压缩步骤：

1. **分析状态转移方程**
2. **确定依赖关系**
3. **选择合适的遍历顺序**
4. **处理边界和中间值保存**
5. **验证正确性**

## 🚨 常见错误和避免方法

### ❌ 常见错误1: 状态定义不清

```java
// 错误：不知道dp[i]具体含义
dp[i] = ?

// 正确：明确定义
dp[i] = 以nums[i]结尾的最大子数组和
```

### ❌ 常见错误2: 边界处理错误

```java
// 错误：忘记初始化
int[] dp = new int[n];

// 正确：正确初始化
int[] dp = new int[n];
dp[0] = nums[0];  // 或其他合理初值
```

### ❌ 常见错误3: 遍历顺序错误

```java
// 错误：使用了尚未计算的状态
for (int i = 0; i < n; i++) {
    dp[i] = dp[i+1] + nums[i];  // dp[i+1]还没计算！
}

// 正确：保证依赖的状态已计算
for (int i = n-2; i >= 0; i--) {
    dp[i] = dp[i+1] + nums[i];
}
```

### ❌ 常见错误4: 状态转移方程错误

```java
// 错误：逻辑不完整
dp[i] = dp[i-1] + nums[i];  // 没考虑重新开始的情况

// 正确：考虑所有可能
dp[i] = Math.max(nums[i], dp[i-1] + nums[i]);
```
